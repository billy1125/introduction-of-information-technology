# 期中考設定

> 本檔是期中考的設定檔。其他文件提到期中考的日期、時間、地點、範圍與計分時，一律以本檔為準。

只涵蓋呂卓勲老師負責的期中考。

## 時間、地點與範圍

| 項目 | 內容 |
|---|---|
| 日期 | 2026.11.06（第 9 週） |
| 地點 | 2115（A 班）、2623（B 班）。B 班不是原上課教室 |
| 題目類型 | 單選題（40 題）、計算/簡答題 |
| 範圍 | 呂卓勲老師所教授的所有教材內容，不含第六章〈五、工業4.0與智慧製造〉 |
| 考卷 | A、B 兩班考卷不同，難度相當；各班另分卷別，卷別之間只有題目順序不同 |
| 佔學期總成績 | 50% |

| 項目 | A 班 | B 班 |
|---|---|---|
| 開始考試 | 13:10 | 09:10 |
| 最晚入場時間 | 13:30 | 09:30 |
| 最早交卷時間 | 13:40 | 09:40 |
| 考試結束 | 16:10 | 12:10 |

- 遲到逾 20 分鐘不得入場，視同缺考。
- 開考起 30 分鐘內不得交卷離場。

## 缺考與補考計分

| 情況 | 結果 |
|---|---|
| 不可抗力，且提出證明 | 可補考，成績以實得分數的 100% 計算 |
| 一般個人因素，但依規定請假並通過 | 可補考，成績以實得分數的 80% 計算 |
| 沒有請假，或請假未通過 | 視同缺考，該次考試 0 分 |

## 成績公布與複查

| 項目 | 內容 |
|---|---|
| 成績公布 | 考試後的第一個週一 |
| 複查期限 | 公布後至當週週三前，逾期不受理 |

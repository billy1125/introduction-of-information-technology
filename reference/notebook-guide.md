# 練習筆記本撰寫規範

本檔為課程練習用 Jupyter 筆記本（`.ipynb`）的通用撰寫規範，不綁定特定課程或學科領域。哪一本筆記本對應哪一份教材，見專案的 `CLAUDE.md` 與 `README.md`。

## 一、存放位置與命名

所有練習筆記本統一集中放在 `notebooks/` 資料夾，不散落於專案根目錄或各章資料夾。檔名對應其服務的教材，採用可直接看出對應關係的英文名稱（例如服務 `02-Computer-Structure.md` 的筆記本命名為 `Computer-Structure-Examples.ipynb`）。

## 二、Cell 的組織方式

每組 Cell 對應教材中的一個章節或一道題目，順序與教材一致。筆記本設計為 **由上往下依序執行**，後面的 Cell 可以依賴前面 Cell 的定義，但不應依賴讀者手動跳著執行的結果。

每個程式碼 Cell 都必須留下 **可見的輸出**，方便學生對照自己的執行結果。沒有輸出的 Cell 等於沒有給學生檢查點，若某個 Cell 本身只做定義，就在結尾補一行印出結果的敘述。

## 三、計算過程的呈現

需要展示推導的題目，計算過程以 LaTeX（`$...$` 行內、`$$...$$` 獨立區塊）寫在 Markdown Cell 中，讓步驟清楚可讀。程式碼負責算出答案，LaTeX 負責解釋這個答案是怎麼來的，兩者搭配而非擇一。

## 四、程式碼風格

僅使用 Python 標準函式庫，不引入外部套件。原因是學生多半在 Google Colab 或臨時環境中執行，任何額外的安裝步驟都會成為障礙。

變數名稱使用中文（如 `總產量`、`良率`），與中文教材的撰寫風格一致，也讓沒有程式設計背景的讀者能直接看懂每一行在算什麼。

## 五、與正文的分工

若教材正文某小節的練習題已整理進對應筆記本並附上計算過程，正文中該小節只需保留一段簡短說明與指向筆記本的連結，不需要在正文重複列出完整題目、計算過程或答案。同一份解答維護在兩個地方，遲早會出現其中一份沒跟上修改的情況。
